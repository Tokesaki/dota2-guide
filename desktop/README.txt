Dota 2 复盘助手（本地版）
========================

怎么用
  1. 双击 Dota2Review.exe
  2. 稍等几秒，浏览器会自动打开 http://localhost:17788
  3. 右下角托盘里有个红色小图标：双击它重新打开页面，右键选"退出"关闭程序

  关掉浏览器不会退出程序，它会继续在后台每小时采集一批高分局出装样本。
  再次双击 Dota2Review.exe 只会打开页面，不会重复启动。

第一次用
  - 打开"比赛复盘"，填你的 Steam 好友代码（游戏里个人资料页的那串数字）
  - 游戏里要打开"公开比赛数据"（设置 → 选项 → 社交），否则 OpenDota 查不到你的比赛

数据存在哪
  C:\Users\你的用户名\.dota2-review\
    data.mv.db   本地数据库（比赛缓存、高分局样本）
    app.log      运行日志，出问题时看这里
  删掉这个文件夹就等于重置。

常见问题
  - 浏览器没自动打开：手动访问 http://localhost:17788
  - 端口被占用：设置环境变量 DESKTOP_PORT=别的端口号 再启动
  - Windows 提示"已保护你的电脑"：点"更多信息" → "仍要运行"（程序没有数字签名）
